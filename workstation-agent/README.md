# Filament Manager Workstation Agent

The workstation agent is the outbound-only bridge between Filament Manager and Cura. Install it under the same desktop account that runs Cura on every Arch Linux and Windows 11 workstation.

It discovers Cura user-data versions, machine instances, sanitized existing material settings, saved print-profile settings, known managed-material edits, and desired-library drift. Before takeover, saved print profiles are read-only sources: global and first-extruder layers are merged, only Filament Manager's approved literal settings are reported, and Cura expressions are omitted rather than evaluated. An Administrator may map any reported source to one existing template or leave it unmapped, then complete the entire takeover atomically. The agent waits until Cura closes, backs up affected user files, and atomically installs Filament Manager's current `Template <material type>` and product material library plus its managed visibility/enforcement plugin. The plugin waits for Cura to finish initialization before aligning the Material Settings plugin's enabled list, merging currency-safe weighted product costs for Cura print estimates, and connecting machine/material enforcement. It preserves unrelated Cura cost preferences and removes only managed GUIDs that disappeared. It favorites Templates, groups manufacturer-less products under `Unknown`, removes only centrally managed material keys from user custom profiles, repairs recoverable duplicate sections, and quarantines malformed bounded files. Changes to approved settings on known managed materials save directly in Filament Manager and synchronize automatically, while new or copied Cura materials are never imported. While Cura is closed, the agent also captures bounded sanitized operational printer/profile/preferences state for ten server-side exact-version recovery points and applies only explicitly confirmed restores after a local rollback backup. It never uploads credentials, endpoints, paths, account sessions, or plugin binaries. It has no listening port, and its credential can be revoked from Filament Manager.

The installers explicitly report fresh installation versus in-place upgrade. Matching Arch Linux and Windows uninstallers remove the per-user agent service/task and private agent files while leaving Cura's currently deployed managed library usable.

See [../docs/CURA_WORKSTATION_AGENT.md](../docs/CURA_WORKSTATION_AGENT.md) for installation, pairing, service operation, synchronization rollback, full Cura recovery, removal, and troubleshooting.
