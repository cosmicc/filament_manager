# Google publication workflow

- 0.8.1 explicitly exports Spool Types, each spool's type, and cached printer duration totals/freshness. Derived activity views stay canonical history queries; existing Print History and Material Segments tabs retain the underlying dates and captured identities. New database fields never expand the export contract implicitly.

- Settings is the Google setup surface; do not restore Integrations. Guided setup accepts a bounded Web OAuth JSON download, validates client fields and exact redirect URI, ignores supplied endpoint URLs, and stores the secret encrypted. Preserve environment-configured clients until explicit adoption. The shared credential helper initializes a private-volume key only when no encrypted printer/Google data exists; a lost key is a recovery failure. Keep the key outside PostgreSQL and never return token/client-secret/state/verifier material in status, audit or logs. Replacing credentials invalidates pending consent and the prior grant, retaining workbook identity.
- OAuth is Administrator-only with CSRF, ten-minute hashed state, encrypted PKCE verifier and exact app-session binding. Consume state before exchanging, reject replay and superseded attempts, and preserve SameSite=Strict. The callback SPA removes query parameters before telemetry and completes using same-origin authenticated POST. The standard server disables raw Uvicorn access logs; proxy operators must omit callback query strings too.
- Use fixed Google origins, verified TLS, bounded requests and sanitized failures. Request only `drive.file`. Workbook creation uses an appProperties UUID, not a name search, to recover after uncertain creation without commandeering another workbook.
- Export only `services/google_workbook.py`'s explicit table/column contracts; adding models/columns never expands disclosure automatically. Include archived rows, immutable profile/template/print snapshots, sparse overrides, calibration and measurements. Flatten included JSON into Settings and Evidence, mark filtered credential/connection keys, retain inert expressions with explicit `stringValue`, and fail closed on size/depth limits rather than silently truncate.
- Read one repeatable-read, read-only PostgreSQL snapshot without locking business rows or loading ORM relationships. Existing mutation jobs plus a complete periodic digest cover every included create/update/delete. Serialize Google jobs/connect/disconnect with the dedicated advisory lock; a worker must skip a busy lock instead of occupying another worker needed for printer monitoring. Persist shared exponential provider backoff. Print deferral reads canonical history only and adds no printer requests.
- Preserve stable destination tab IDs and unrelated tabs. Tag owned targets/staging with developer metadata, clean only exact owned staging, batch under recommended payload limits and pace requests to at most 48 per minute, then atomically copy/format/delete staging. Limit snapshots to two million cells and 32 MiB serialized content; refuse oversize data without truncation. Do not delete a tab merely because its name resembles an app tab. Owner edits are warned, never imported, and repaired by changed/forced publication. The retained legacy Inventory tab is not updated.
- Tests must cover real PostgreSQL schema/snapshot/export parity, auth and CSRF, single-use session-bound state, encrypted grant readback, disconnected/failed/coalesced publishing, archived rows, deleted rows, formula safety, staging failure, links/filters/protection, stable IDs, and desktop/mobile Settings. Validate provider request structures against Google's discovery schema. Live Google sign-in cannot be claimed without an operator-configured OAuth project and consent.
- Deployment migration `d8e9f012a3b4` adds only private connection state. Keep `EXPECTED_SCHEMA_VERSION`, Compose/Swarm variables, `.env.example`, setup docs and frontend contract aligned. No renderer increment or macro replacement is needed unless their own behavior changes.
