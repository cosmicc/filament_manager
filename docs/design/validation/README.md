- `build-plates-v040.png` documents the compact 0.4.0 physical-plate summary, intrinsic-width desktop actions, grouped sides, and maintenance-history layout.
- `build-plates-mobile-v040.png` documents the same information-preserving layout with full-width mobile touch actions.

- `inventory-views-mobile-v041.png` documents the compact Cards presentation and theme-correct stacked search/filter/view toolbar on a phone-sized viewport.
- `dashboard-printer-state-light-v057.png` and `dashboard-printer-state-dark-v057.png` document the live Moonraker/Klipper status with its stored print thumbnail, progress, temperatures, elapsed time, filament use, and cost under both base color modes.
- `dashboard-printer-state-mobile-v057.png` documents the same information-preserving current-print state on a phone-sized viewport.
